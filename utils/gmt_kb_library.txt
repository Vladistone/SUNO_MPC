# 2.0 CONNECTIVITY & INTERFACES

2.3.0	Количество виртуальных субинтерфейсов (логических портов), выделяемых под обслуживание одного активного слоя управления.		[DEPRECATED]
2.4.0	Физические интерфейсы подключения. Nucleus 2 использует USB-HID для эмуляции клавиатуры и Ethernet (ipMIDI) для скоростной передачи Mackie Control/HUI пакетов.		[DEPRECATED]
2.5.0	Сетевые MIDI-транспорты. Стандартный профиль Logic требует настройки ipMIDI Monitor на 6 активных портов без Loopback-петли.		[DEPRECATED]
2.6.0	Прикладные маппинг-протоколы. Специфицирует набор карт команд, транслируемых ядром (Mackie Control, HUI, CC-номера или кастомный OSC).		[DEPRECATED]
2.7.0	Флаг активации эмуляции USB QWERTY клавиатуры. Позволяет физическим кнопкам пульта посылать стандартные горячие клавиши ОС.		[DEPRECATED]
2.8.0	ASCII Hot Key. Клавиатурная комбинация (например, Shift+S), программируемая в утилите SSL Logictivity. Посылается пультом при нажатии кнопки DAW-слоя для мгновенной перефокусировки веб-интерфейса Suno Studio.		[DEPRECATED]
2.9.0	Флаги поведения QWERTY-эмуляции. FOLLOW_KEY_STATE заставляет пульт слать явные сигналы зажатия модификаторов (Shift/Ctrl/Cmd/Alt), необходимые для шорткатов навигации таймлайна.		[DEPRECATED]

3.8.0	Non-Registered Parameter Number. Поддержка составных 14-битных MIDI-сообщений для глубокого управления тонкими параметрами синтезаторов.		[DEPRECATED]
3.9.0	System Exclusive. Способность ядра принимать и парсить сырые бинарные дампы системных данных напрямую от железа.		[DEPRECATED]
