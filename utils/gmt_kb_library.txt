# 1.0 META DATA & DOCUMENTATION
1.1.0	Брендирование профиля. Для Solid State Logic запускает специфические алгоритмы фильтрации ASCII и MCU логов в терминале ядра, а также активирует фирменный красный водяной знак в сайдбаре.
1.2.0	Unique Profile Database Key. Уникальное имя-идентификатор файла на жестком диске. Используется движком Node.js для поиска карт. Пишется в нижнем регистре строго без расширения.
1.3.0	Коммерческое наименование прибора. Используется для вывода в шапке и текстовых логах сервера управления.
1.4.0	Прямая ссылка на официальное руководство пользователя (Owner Manual PDF) для оперативной сверки аппаратных узлов.
1.5.0	Ссылка на заводскую карту MIDI Implementation спецификации производителя, где расписаны HEX-коды SysEx и CC-номера.
1.6.0	Ссылка на документацию текущей ветки Git-репозитория разработки и логирования проекта SUNO_MPC.

# 2.0 CONNECTIVITY & INTERFACES
2.1.0	Количество одновременно активных и опрашиваемых сервером протоколов (например, параллельная работа MCU + HID).
2.2.0	Количество независимых DAW-слоев. SSL Nucleus поддерживает до 3-х слоев, позволяя одновременно управлять тремя разными DAW (Logic, Pro Tools, Cubase) через ipMIDI порты 1-6.
2.3.0	Количество виртуальных субинтерфейсов (логических портов), выделяемых под обслуживание одного активного слоя управления.
2.4.0	Физические интерфейсы подключения. Nucleus 2 использует USB-HID для эмуляции клавиатуры и Ethernet (ipMIDI) для скоростной передачи Mackie Control/HUI пакетов.
2.5.0	Сетевые MIDI-транспорты. Стандартный профиль Logic требует настройки ipMIDI Monitor на 6 активных портов без Loopback-петли.
2.6.0	Прикладные маппинг-протоколы. Специфицирует набор карт команд, транслируемых ядром (Mackie Control, HUI, CC-номера или кастомный OSC).
2.7.0	Флаг активации эмуляции USB QWERTY клавиатуры. Позволяет физическим кнопкам пульта посылать стандартные горячие клавиши ОС.
2.8.0	ASCII Hot Key. Клавиатурная комбинация (например, Shift+S), программируемая в утилите SSL Logictivity. Посылается пультом при нажатии кнопки DAW-слоя для мгновенной перефокусировки веб-интерфейса Suno Studio.
2.9.0	Флаги поведения QWERTY-эмуляции. FOLLOW_KEY_STATE заставляет пульт слать явные сигналы зажатия модификаторов (Shift/Ctrl/Cmd/Alt), необходимые для шорткатов навигации таймлайна.

# 3.0 SUPPORT SysEX, MPE, OSC & EXPRESSION
3.1.0	Полифонический послеартикуляционный тип давления. Передача независимых векторов давления для каждой отдельной зажатой клавиши.
3.2.0	Монофонический (Channel) послеартикуляционный тип давления. Передача единого усредненного вектора давления со всей поверхности.
3.3.0	Наличие и опрос подпружиненного колеса Pitch Bend для плавного смещения частоты тона (14-битное разрешение).
3.4.0	Стандартное колесо модуляции (WHEEL_MODLTN). Передача индекса модуляции по MIDI CC#1 для управления глубиной LFO и фильтрами.
3.5.0	Сенсорная лента / 2D тачпад (XY_PAD_RIBBN) для многомерного скольжения пальцем.
3.6.0	Разрядность фейдеров. 14-битное разрешение (16384 шага) обеспечивает прецизионную точность локомоции моторизованных фейдеров по протоколу Pitch Bend, исключая ступенчатость.
3.7.0	Поддержка духовых контроллеров дыхания (передача потока данных по стандартному каналу MIDI CC#2).
3.8.0	Non-Registered Parameter Number. Поддержка составных 14-битных MIDI-сообщений для глубокого управления тонкими параметрами синтезаторов.
3.9.0	System Exclusive. Способность ядра принимать и парсить сырые бинарные дампы системных данных напрямую от железа.

# 4.0 MECHANICAL & LED FEEDBACK
4.1.0	Разрешение на подачу управляющего напряжения на моторы фейдеров со стороны сервера при изменении автоматизации в DAW.
4.2.0	Активация слежения за емкостным датчиком кноба фейдера для предотвращения сопротивления мотора руке инженера.
4.3.0	Наличие шаговых моторов внутри поворотных энкодеров для физического создания тактильных упоров и шагов (Detents).
4.4.0	Включение светодиодных колец вокруг энкодеров для визуализации значений панорамы или уровней без взгляда на экран.
4.5.0	Режимы свечения колец LED: single_dot (панорама), boost_cut (эквалайзер от центра), wrap (уровень от нуля до максимума), spread (ширина стереобазы).
4.6.0	Светодиодная синхронизация кнопок. Разрешает лампам Solo, Mute, Select мгновенно загораться по команде от сервера.
4.7.0	Включение индикаторов аудио-уровней (Peak Meters) на канальных линейках для контроля перегрузки входов.
4.8.0	Количество дискретных светодиодных сегментов (делений) в одной полосе канального пик-метра.
4.9.0	Общее количество кнопок на панели, оснащенных встроенными светодиодными индикаторами состояния.
4.10.0	Цветовая архитектура светодиодов на кнопках пульта: monochrome (одноцветные) или многоцветные RGB-матрицы.

# 5.0 FEEDBACK: DISPLAY STRIP SPECS
5.1.0	Scribble Strips дисплеи. Светодиодные экраны над каждым каналом. Выводят имена треков, параметры плагинов и значения панорамы.
5.2.0	Поддержка динамического обновления экранов. Флаг разрешает серверу слать ASCII-потоки при смене фокуса трека или автоматизации.
5.3.0	Светодиодная мост-индикация (Meter Bridge). Визуализация уровней сигналов каналов непосредственно на дисплейной панели.
5.4.0	Наличие физического 7-сегментного диодного индикатора для отображения глобального таймкода проекта.
5.5.0	Текущий параметр отображения времени: вывод в формате Timecode (SMPTE) или Bars/Beats (такты и доли).
5.6.0	Количество физических символьных ячеек в строке 7-сегментного индикатора таймкода (стандарт MCU — 10 знаков).
5.7.0	Лимит символов для Mackie Control (MCU). Протокол Logic MCU жестко ограничивает длину имени канала до 7 символов на Scribble Strip дисплее.
5.8.0	Лимит символов для протокола Pro Tools HUI. Ограничивает ячейку дисплея строго до 4 символов, требуя агрессивного сокращения названий.
5.9.0	Visual Spacer. Символ-разделитель между текстовыми ячейками каналов на общем двухстрочном LCD-дисплее.
5.10.0	Общая формула разрешения и геометрии дисплейной матрицы текстового блока (например, 2 строки по 56 символов).

# 6.0 HARDWARE CONTROL ARCHITECTURE
6.1.0	Емкостная сенсорность фейдеров. Фиксирует прикосновение пальца к металлическому кнобу для мгновенного перехвата автоматизации (Touch) в DAW.
6.2.0	Моторизация фейдеров (FADER_MOTORIZED). Наличие сервомоторов привода для физического отображения положения регуляторов микшера в реальном времени.
6.3.0	Наличие выделенного изолированного 9-го фейдера, намертво привязанного к мастер-шине (Master Fader) микшера.
6.4.0	Fader Flip Mode. Режим мгновенной рокировки параметров: меняет местами значения регулировок между линейными фейдерами и поворотными V-Pot энкодерами.
6.5.0	Rotary Jog Wheel. Оптическое колесо навигации. Отвечает за ускоренное перемещение курсора по таймлайну проекта, зуммирование или скраббинг аудио.
6.6.0	Режим аудио-скраббинга. Переводит Jog Wheel в режим покадрового прослушивания звукового трека (Scrub) под курсором.
6.7.0	Количество физических канальных линеек (Channel Strips) на панели управления (для Nucleus — 8, для US2400 — 24).
6.8.0	Общее количество установленных на поверхности скользящих потенциометров (фейдеров).
6.9.0	Общий счетчик стандартных короткоходных кнопок без фиксации, размещенных на всей поверхности пульта.
6.10.0	Количество бесконечных вращаемых цифровых энкодеров (V-Pots) со светодиодной индикацией вокруг вала.
6.11.0	Количество энкодеров, имеющих встроенную функцию клика при нажатии на сам вал (V-Pot Push Switch).
6.12.0	Количество центральных системных софт-клавиш, подлежащих кастомному программированию пользователем.
6.13.0	Количество кнопок переключения глобальных подрежимов автоматизации и навигации.
6.14.0	Количество выносных утилитарных переключателей на боковых частях корпуса прибора.
6.15.0	Количество гнезд (Jack 1/4) на задней панели для подключения ножных педалей экспрессии и сустейна.	

# 7.0 DAW NAVIGATION, TRANSPORT
7.1.0	Bank Shift. Скроллинг линеек микшера DAW фиксированными аппаратными блоками строго по 8 каналов за одно нажатие.
7.2.0	Channel Shift. Смещение фокуса микшера на 1 одиночный трек влево или вправо для точечного позиционирования.
7.3.0	Наличие выделенных аппаратных кнопок-модификаторов (Shift, Ctrl, Alt, Cmd) для изменения логики смежных команд.
7.4.0	Наличие и опрос горизонтальных тактильных стрелок (Left/Right) для перемещения по сетке регионов таймлайна.
7.5.0	Наличие и опрос вертикальных тактильных стрелок (Up/Down) для вертикального перемещения по трекам проекта.
7.6.0	Глобальная мастер-кнопка переключения режимов автоматизации на всей поверхности консоли.
7.7.0	Назначение режимов автоматизации: READ, WRITE, TOUCH, LATCH, TRIM, А так же наличие кнопки для REC./ARM.
7.8.0	Назначение кнопок транспорта: STOP, PLAY, REC, PREV, NEXT, CYCLE
7.9.0	Альтернативный редим для кнопок PREV -> RESER ZERO, NEXT -> GO to END, LOOP ON/OFF 
7.10.0	Подрежимы верхнего ряда кнопок (Default Key Set). Переключают V-Pots энкодеры на управление параметрами: TRACK (микшер), PAN (панорама), EQ (параметрический эквалайзер), SEND (посылы), PLUGIN (эффекты), INSTR (виртуальные инструменты).
7.11.0	Специфические подрежимы для протокола Pro Tools HUI. Жестко переключают логику шины на посылы групп A-E и управление мьютированием.
7.12.0	Глобальное назначение скользящего фейдера по умолчанию в чистой сессии (Volume — управление громкостью канала).
7.13.0	Глобальное назначение вращаемого энкодера по умолчанию в чистой сессии (Pan — управление панорамой).
7.14.0	Событие при физическом нажатии на вал энкодера по умолчанию (Reset — мгновенный сброс панорамы в ноль/центр).
7.15.0	Назначение базовой нижней кнопки канальной линейки (Select — выбор трека и передача на него фокуса ввода).
7.16.0	Назначение средней кнопки канальной линейки (Mute — мгновенное глушение аудиосигнала в канале микшера).
7.17.0	Назначение верхней кнопки канальной линейки (Solo — изоляция канала и отключение остальных линеек).
7.18.0	Назначение дополнительной четвертой альтернативной кнопки на канальной линейке (по умолчанию отсутствует — NA).
